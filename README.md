
## 🤖 Telegram-бот

**[Natalia Data Assistant](https://t.me/natalia_data_helper_bot)**

Telegram-бот для анализа вакансий и помощи в поиске работы.

**Возможности:**
- Анализ вакансий.
- Выделение ключевых требований работодателя.
- Оценка соответствия кандидата вакансии.
- Помощь в подготовке к трудоустройству.

**Технологии:**
- Python
- Telegram Bot API
- Groq API
- Railway (деплой)
