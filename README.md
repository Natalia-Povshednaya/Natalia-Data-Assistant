
## 🤖 Natalia Data Assistant

**[Открыть Telegram-бота](https://t.me/natalia_data_helper_bot)**

AI-ассистент для работы с данными и решения аналитических задач.

### Возможности
- Ответы на вопросы по анализу данных.
- Помощь в написании и разборе SQL-запросов.
- Объяснение Python и библиотек Pandas.
- Помощь в расчёте аналитических метрик.
- Разбор статистики и A/B-тестов.
- Поддержка диалога с сохранением контекста предыдущих сообщений.
- Возможность очистить историю диалога.

### Технологический стек
- Python
- python-telegram-bot
- Groq API (GPT-OSS-20B)
- Railway (облачный деплой)
